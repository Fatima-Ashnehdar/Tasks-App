Eventloop:
میدونستم چه طور کار میکنه و برای مثالش صرفا از چیزایی که توی مکین یاد گرفته بودم استفاده کردم.
از تسک ساده استفاده کردم و اون رو توی console نشون دادم.

Closure & Debounce:
فقط تعریف تئوری رو بلد بودم.
فکر کردم برای اینکه نشونش بدم بهتره توی صفحه باشه تا توی console
و ببینم چه اتفاقی داره میفته تا بهتر درکش کنم
برای تحقیق از سایت های ایرانی کمک گرفتم و مثال ها رو دیدم.
توی تسک debounce یه قسمتی از کدم مشکل داشت و از هوش مصنوعی کمک گرفتم تا ببینم مشکل ازکجاست
